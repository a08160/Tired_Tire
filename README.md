
# Tired Tire: AI 기반 타이어 상태 진단 서비스

## 📌 개요 (Overview)
**Tired Tire**는 타이어 상태(공기압, 균열 등)를 AI 기반 분석을 통해 자동 진단하고, 위험도 및 교체 필요성을 사용자에게 직관적으로 전달하는 스마트 차량 관리 서비스입니다. 본 프로젝트는 공공 및 민간 데이터를 수집·학습하여 모바일 앱에서 타이어 자가 진단을 가능하게 하는 것을 목표로 합니다.

---

## 🧠 문제 정의 (Problem Definition)

1. **객관적 기준의 부재**
   - 운전자 다수는 타이어의 마모/손상 여부를 주관적으로 판단
   - 46%의 점검 타이어가 부적합 상태이며, 이 중 37%는 공기압 문제

2. **진단 회피 요인**
   - "비용", "시간", "귀찮음"으로 인해 정기 점검을 기피

3. **기존 앱 서비스의 한계**
   - 대부분 차량 정보 저장/가이드만 제공
   - **AI 기반 자동 점검 기능 부재**

- 점검 이력 자동 저장

## 🧪 모델 구조 및 개발 흐름 (Model Development)

### 1. 타이어 인식 모델
- **MobileNetV2 기반** 경량화 모델
- 타이어 유무 및 외형 인식

### 2. 공기압 추출 모델
- 타이어·휠 세그멘테이션 → 특정 포인트 기반 면적 비율 계산
- 위험도 (정상/주의/위험) 등급 제공

### 3. 크랙 검출 모델
- 이미지 슬라이딩 + Crop + Pseudo Mask 생성
- 크랙 면적 기반 **정량적 위험도 점수** 제공 (0~100)
